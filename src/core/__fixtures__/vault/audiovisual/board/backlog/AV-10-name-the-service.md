# AV-10 — Name the service

**Status:** Backlog — drafted 2026-08-26
**Repo:** `pangolin-audiovisual`
**Area:** naming, positioning

---

## Context

`pangolin-audiovisual` is an accurate repo name and a bad product name. It describes a
media category, not a job, and it gives a user no idea what the thing does. Now that the
project has a thesis worth defending — bring-your-own-recorder transcription, local and
private, no metered minutes — the name should carry it.
